- [x] انتقال رنگ‌های `fd*` و فونت‌های متن موجود در مرجع.
- [x] آیکن‌های ناوبری و ساختار نوار پایین پنج‌بخشی.
- [ ] تمام XMLها، modalها، انیمیشن‌ها، ابعاد و فاصله‌های اصلی.
- [x] رندر امن نتیجه با CSS و فونت‌های اصلی، بدون قفل.
- [ ] همهٔ interactionهای اصلی؛ JS عمداً منتقل نشده و همهٔ رفتارها هنوز جایگزین بومی ندارند.
- [ ] تم تاریک دقیق، زبان فارسی/انگلیسی، RTL/LTR، فونت بزرگ و TalkBack.
- [ ] بازگشت و بازیابی state دقیق تمام صفحات؛ نسخهٔ فعلی صفحات تو در تو را به جستجو برمی‌گرداند.
- [ ] screenshot regression با اپ اصلی در اندازه و density یکسان.

نوار پایین اکنون ۵ مورد مانند ساختار اصلی دارد؛ پروفایل فعلی محلی است و صفحهٔ AI به gateway تنظیم‌شده متصل می‌شود. این ساختار به معنی تطابق کامل محتوا و رفتار نیست.
