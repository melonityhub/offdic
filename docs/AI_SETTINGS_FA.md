# تنظیم API هوش مصنوعی

از **بیشتر ← تنظیمات AI / API** یا دکمهٔ تنظیمات در تب AI وارد شوید.

- **نوع اتصال:** Gateway اختصاصی یا OpenAI-compatible Chat Completions.
- **آدرس:** URL کامل HTTPS؛ برای Chat Completions شامل `/v1/chat/completions`، برای gateway مسیر `/ai`. برنامه چیزی به URL اضافه نمی‌کند. `http`، نام کاربری/رمز در URL، query و fragment رد می‌شوند.
- **نام مدل:** برای Chat Completions الزامی؛ همان شناسه‌ای که ارائه‌دهنده پشتیبانی می‌کند.
- **API key / توکن:** با Keystore رمز می‌شود؛ کلید قبلی نمایش داده نمی‌شود. خالی گذاشتن، کلید قبلی را نگه می‌دارد. برای حذف، گزینهٔ حذف کلید را تیک بزنید.
- **دستور سیستم:** فقط برای Chat Completions ارسال می‌شود.
- **مهلت:** بین ۱۵ تا ۱۲۰ ثانیه برای پاسخ؛ زمان اتصال ۱۵ ثانیه است.

با تغییر دامنه، پورت یا نوع اتصال، کلید قبلی خودکار به مقصد جدید ارسال نمی‌شود؛ باید کلید را دوباره وارد یا حذف کنید. کلید واردشده در چرخش صفحه/instance state ذخیره نمی‌شود؛ اگر هنوز ذخیره نکرده‌اید، دوباره وارد کنید. screenshot و autofill صفحهٔ تنظیمات غیرفعال‌اند.

«ذخیره تنظیمات» هیچ درخواست شبکه‌ای ندارد. «آزمایش اتصال» پس از تأیید، پیام `Reply only OK.` می‌فرستد و دریافت پاسخ متنی را بررسی می‌کند؛ ممکن است هزینه داشته باشد. تست از مقادیر فعلی فرم استفاده می‌کند و آن‌ها را ذخیره نمی‌کند. کلیدتان را فقط به دامنهٔ مورد اعتماد بدهید.

Gateway قرارداد `{"prompt":"..."}` → `{"answer":"..."}` دارد. حالت مستقیم از درخواست استاندارد `model/messages/stream=false` و پاسخ `choices[0].message.content` استفاده می‌کند؛ APIهای Responses، Gemini-native یا Anthropic-native مستقیماً پشتیبانی نمی‌شوند، مگر از gateway سازگار استفاده کنید.

خطاهای HTTP 401/403 (کلید/مجوز)، 404 (مسیر/مدل)، 429 (نرخ/اعتبار) و 5xx (سرویس) پیام مشخص دارند. کلید و بدنهٔ خام خطای ارائه‌دهنده در خطا/لاگ بازتاب داده نمی‌شوند. endpoint واقعی، کلید و مدل متعلق به شما لازم است؛ این تنظیمات سرویس اصلی را دور نمی‌زنند.
