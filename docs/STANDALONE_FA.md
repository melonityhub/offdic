# نسخهٔ مستقل بدون پروژهٔ اصلی

در ریشه اجرا کنید:

```sh
python3 tools/export_standalone.py
```

خروجی: `artifacts/offdic-standalone.zip`؛ شامل پروژهٔ Kotlin، wrapper، دیتابیس نمونه، تست‌ها و gateway است. پوشه‌های مرجع `sourcecode/`، `dict/`، `res/` و `assets/` در ریشه، manifest اصلی، تاریخچهٔ Git، فایل‌های build، کلیدها و دیتابیس کامل در ZIP نیستند. منابع مورد استفادهٔ اپ داخل `app/src/main` به‌طور ضروری باقی می‌مانند.

فایل `SOURCE_MANIFEST.json` امکان کنترل SHA256 هر فایل را می‌دهد. خروجی از allowlist ساخته می‌شود، نه کپی کل checkout. CI نیز ZIP مستقل را به‌عنوان artifact منتشر می‌کند.

## شاخه یا مخزن مستقل

این جلسه به شاخهٔ `arena/bae84833-offdic` محدود است و عامل هیچ شاخهٔ دیگری ایجاد نمی‌کند. روش توصیه‌شده برای شما: ZIP را **در پوشهٔ خالی دیگری** استخراج کنید و یک مخزن جدید از همان محتوا بسازید. در Android Studio همان پوشه را باز کنید؛ پروژه برای بیلد به مخزن اصلی وابسته نیست.

اگر بعداً خودتان در GitHub شاخهٔ دیگری در همین مخزن می‌خواهید، می‌توانید محتوای این خروجی را در یک checkout جداگانه روی شاخهٔ موردنظر قرار دهید. این کار با مخزن جدید فرق دارد: شاخهٔ معمولی همچنان تاریخچهٔ قدیمی را در Git نگه می‌دارد. ZIP مستقل هیچ تاریخچه‌ای ندارد. از پاک کردن پوشهٔ مخزن جاری یا `.git` آن برای این کار استفاده نکنید.
