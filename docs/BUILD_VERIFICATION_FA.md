## خطاهای پیدا و اصلاح‌شده

۱. شکست CI در `android-actions/setup-android`: پیش از رسیدن به کامپایل. به SDK از قبل نصب‌شدهٔ runner ثابت Ubuntu 24.04 منتقل شد.
۲. خطای AAPT برای `?tabBarDefault`: ویژگی و مقدار تم تعریف شد؛ تست مستقل برای ارجاعات ویژگی‌های تم اضافه شد.
۳. خطاهای Kotlin بر اثر تداخل `foreground/background` با ویژگی‌های `View`: نام‌ها به `pageTextColor/pageBackgroundColor` تغییر یافتند.
۴. خطای lint برای `windowLightNavigationBar` مخصوص API 27: به `values-v27` منتقل شد؛ تم API 26 نوار تیره دارد تا دکمه‌ها خوانا بمانند.
۵. خطای آماده‌سازی فایل دوربین/محدودیت دسترسی: به پیام خطا و پاکسازی فایل موقت تبدیل شد، نه crash بدون مدیریت.
۶. خطر ارسال کلید قبلی به دامنه/پورت/API جدید: محدودهٔ اعتبارنامه کنترل می‌شود. در درخواست عادی نیز endpoint و کلید هنگام نمایش تأیید، snapshot یکسان دارند.
۷. Wrapper استاندارد Gradle 8.9 اضافه شد؛ SHA256 توزیع از endpoint رسمی دریافت و ثبت شد.

## دابل‌چک خروجی مستقل

- ZIP از allowlist مشخص ساخته می‌شود؛ هیچ Java/Smali مرجع، manifest اصلی، `.git`، build، کلید خصوصی یا دیتابیس کامل وارد نمی‌شود.
- فایل نمونه و fixtureهای تست مستقل در ZIP هستند؛ تست POS دیگر به `sourcecode` نیاز ندارد.
- تولید تکراری ZIP از محتوای یکسان، خروجی یکسان می‌دهد.
- SHA256 هر فایل در `SOURCE_MANIFEST.json` ثبت می‌شود.
- در CI، خروجی واقعاً استخراج و جداگانه بیلد می‌شود.

## محدودیت‌های تأیید

بیلد و تست موفق به معنی «هیچ باگی وجود ندارد» نیست. این موارد با داده/دستگاه واقعی شما باید بررسی شوند:

- API key، endpoint و مدل واقعی ارائه‌دهندهٔ شما؛ تست‌های gateway از مدل mock استفاده می‌کنند.
- دوربین دستگاه فیزیکی، firmwareهای مختلف و نسخه‌های Android غیر از emulator API 35.
- دانلود مدل ترجمه و کیفیت ترجمهٔ واقعی؛ تست زبان‌ها بدون تضمین دسترسی Google در تمام شبکه‌ها.
- دیتابیس کامل حجیم، عملکرد و کمبود فضا/قطع برنامه حین import.
- تطابق تصویری و عملکردی صددرصد با اپ اصلی؛ چک‌لیست قابلیت‌های ناقص همچنان معتبر است.

artifactهای `build-results`، `android-test-reports` و `offdic-standalone` در صفحهٔ اجرای CI قابل دریافت‌اند. محیط محلی این جلسه همچنان Android SDK ندارد؛ اعتبار بیلد اندروید از runner واقعی CI است، نه تست‌های Python.
