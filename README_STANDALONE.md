# Offdic — بازسازی مستقل Kotlin

واژه‌نامهٔ آفلاین فارسی ↔ انگلیسی. این مخزن فقط سورس قابل‌بازتولید اپ را دارد: پروژهٔ Kotlin در
`app/` تنها منبع تولید APK است. هیچ پوشهٔ Java/Smali مرجع، تاریخچهٔ git، خروجی build یا دیتابیس
کامل داخل آن نیست.

## قابلیت‌ها

- جستجوی پیشوندی فارسی/انگلیسی، تشخیص زبان، صفحه‌بندی و escaping ایمن برای LIKE؛ هر ردیف نتیجه
  پیش‌نمایش ترجمهٔ همان واژه را نشان می‌دهد.
- معنی، مثال، نقش دستوری، CEFR، برچسب‌های دستوری، آوانگاری، مترادف/متضاد، شکل‌های صرفی و لینک
  اصطلاح‌ها.
- علاقه‌مندی، تاریخچه، کپی/اشتراک‌گذاری، دریافت متن از سایر برنامه‌ها.
- تلفظ US/UK با TTS دستگاه و ورود صوتی با سرویس تشخیص گفتار دستگاه.
- حالت تاریک و اندازهٔ نوشته؛ نوار پنج‌بخشی؛ صفحهٔ واژهٔ خودکفا در WebView محدودشده با fallback
  بومی اگر WebView از کار بیفتد.
- دوربین/انتخاب تصویر و OCR لاتین و ترجمهٔ دستگاه انگلیسی/فارسی با ML Kit.
- واژهٔ روز محلی و ویجت قابل resize.
- تنظیمات AI/API برای هر endpoint سازگار با OpenAI (راهنما: `docs/AI_SETTINGS_FA.md`).

## ابزارهای لازم و بیلد

JDK 17، Gradle 8.14.5 (از wrapper)، Android SDK Platform 35، دسترسی به Google Maven و Maven
Central. حداقل دستگاه API 26.

```sh
./gradlew :app:assembleDebug :app:lintDebug
# app/build/outputs/apk/debug/app-debug.apk
```

دیتابیس کامل را بعد از نصب از «بیشتر ← وارد کردن دیتابیس کامل SQLite» وارد کنید
(`docs/DATABASE_FA.md`). نمونهٔ کوچک به‌صورت خودکار بسته‌بندی می‌شود.

## بررسی بدون Android SDK

```sh
python3 tools/test_contract.py
python3 tools/test_gateway.py
python3 tools/test_standalone.py
```

۲۰ آزمون میزبان پاس می‌شوند (۱۴ قرارداد/منابع، ۵ gateway با upstream ساختگی، ۱ خروجی مستقل).
جزئیات در `docs/BUILD_VERIFICATION_FA.md`.

## سرویس AI اختیاری

`gateway/server.py` یک پروکسی کوچک سازگار با OpenAI است تا کلید مدل روی سرور بماند؛ با
متغیرهای محیطی پیکربندی و پشت HTTPS اجرا می‌شود.

## ساختار

| مسیر | کاربرد |
|---|---|
| `app/` | پروژهٔ Kotlin؛ تنها منبع APK |
| `gateway/` | سرویس مستقل AI برای استقرار پشت HTTPS |
| `tools/` | آزمون‌ها و اسکریپت‌های میزبان |
| `dbsample/` | نمونهٔ SQLite و گزارش ساختار |
| `docs/` | راهنماها و گزارش بررسی |

شناسهٔ اپ `org.offdic` است. مجوز فونت‌های مالکیتی و حق استفاده از منابع باید پیش از انتشار
بررسی شود؛ متن مجوز همراه فونت‌ها حفظ شده است.
